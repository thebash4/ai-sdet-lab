# AI SDET Lab — User Registration Practice App

Small React + TypeScript + Vite practice app for a client-side registration form.

Passwords are validated in the browser only and are **never** written to localStorage. Stored practice records include id, name, email, and createdAt.

## Commands

```bash
npm install
npm run dev
npm run build
```

## AI-Native SDET Lab

This repository is a hands-on environment for practicing:
- Playwright automation with TypeScript
- AI-assisted test investigation and implementation
- Parallel AI agents and Git worktrees
- GitHub pull requests and CI workflows
